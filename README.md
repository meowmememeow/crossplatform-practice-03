# Study Explorer

Практическая работа №3, вариант 0.

Автор: Коромыслова Диана Дмитриевна, ТРПО23-2.

Настольное приложение на Electron для просмотра каталога и открытия файлов через системные ассоциации. Безопасный IPC через `preload.cjs`, изоляция renderer, проверка путей.

Основные файлы находятся в `app/`. Зависимости фиксируются `app/package-lock.json`.

| Команда (в `app/`) | Назначение |
| --- | --- |
| `npm ci` | Установка точных зависимостей |
| `npm start` | Запуск приложения |
| `npm test` | Проверки файловых операций |
| `npm run dist:win` | Сборка NSIS для Windows x64 |

Для Windows также существует `app/Start_Windows.cmd`.
